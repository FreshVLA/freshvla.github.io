The central idea

One action,
two timescales.

Watch a robot open a pot. Over several frames, the lid lifts clear. From one frame to the next, the gripper makes small adjustments at the handle.

Substage scale
Tracks how the task progresses across a longer span of video.
Execution scale
Captures local motion left over after accounting for that progress.

Abstract

Learning actions from video

A video can show how an object moves without recording the command that moved it. FreshVLA learns to represent those visual changes, then uses robot demonstrations to connect them to control.

Method

From visual changes to robot actions

FreshVLA first learns how a scene changes, then uses those representations to train a language-conditioned policy.

1

Find the motion

DynaAdapter learns which visual patches change as the gripper approaches and moves an object.

High-pass visual prior
2

Separate the timescales

A substage latent tracks slower progress. An execution latent describes the local residual motion.

Frequency regularization
3

Learn the controls

A frozen encoder supplies targets while a flow-matching policy jointly denoises latent actions and robot actions.
